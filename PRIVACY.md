# Repository Data Policy

This repository is intended to contain GovSec source code, tests, documentation, and sanitized technical evidence.

Do not commit:

- customer data;
- regulated records;
- private conversations;
- production credentials;
- signing private keys;
- deployment secrets;
- employee records;
- live customer identifiers;
- unredacted operational logs from customer environments.

Demonstration evidence published in this repository must use synthetic resources or otherwise be explicitly reviewed and approved for public disclosure.

Repository secret scanning and release review are safeguards, not substitutes for a formal privacy or data-governance assessment.
